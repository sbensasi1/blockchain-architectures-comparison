# Comparaison entre blockchain publique, registre permissionné et base de données classique

Auteur : BEN SASI SAAD EDDINE

## 1. Question choisie
Comment choisir entre une blockchain publique, un registre distribué et une base de données classique pour assurer la traçabilité d'une chaîne d'approvisionnement multi-acteurs ?

## 2. Démarche
1. Définition d'un cas concret de traçabilité logistique impliquant plusieurs acteurs concurrents et des auditeurs.
2. Analyse des caractéristiques techniques de chaque architecture (gouvernance, modèle de confiance, immuabilité, confidentialité, performances et coûts).
3. Élaboration d'un tableau comparatif multicritère et formulation d'une recommandation architecturale hybride.

## 3. Résultat obtenu
Le rapport complet est disponible dans le fichier PDF du dépôt. Il montre qu'un **registre distribué permissionné** offre le meilleur équilibre entre confidentialité commerciale et auditabilité partagée, éventuellement complété par un ancrage périodique d'empreintes cryptographiques sur une blockchain publique.

## 4. Sources
- Nakamoto, S. (2008). *Bitcoin: A Peer-to-Peer Electronic Cash System*.
- Yaga, D., Mell, P., Roby, N., & Scarfone, K. (2018). *Blockchain Technology Overview* (NISTIR 8202).
